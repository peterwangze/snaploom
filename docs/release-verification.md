# Snaploom 交付验收

对照范围为 Snipaste 2.11.3 免费版和专业版。编号与 [调研功能矩阵](snipaste-research.md) 一致。

| 范围 | 实现与验证边界 |
| --- | --- |
| C01–C04 截图 | 区域、定时、历史选区、窗口、屏幕、白板、取色和放大镜均有入口。Windows/X11 已执行原生取图测试。Windows 控件识别依赖 UI Automation，macOS 控件识别依赖辅助功能权限。Wayland 通过系统截图门户采集，通用门户缺少控件级探测和独立光标开关。 |
| C05–C09 输出和识别 | 已实现复制、贴图、保存、自动保存、打印、复制为文件、命令输出、本地 OCR、二维码和条码。圆角和输出阴影由应用合成。Windows 原生分享面板和 Listary 联动仍有差距。 |
| C10 显示兼容性 | Windows 150% 显示器实测，64×48 DIP 导出 96×72 物理像素。自动化包含负坐标和混合缩放的模拟帧。仍需要真实混合缩放多屏、屏幕热插拔和 HDR 环境验收，HDR 色调映射未实现。 |
| A01–A03 标注 | 基本画笔、几何工具、马赛克、模糊、实色遮盖、文字样式、序号、放大、旋转、修改及撤销已实现，自动化覆盖标注导出和裁剪。完整色板共享、部分进阶样式和高 DPI 的单物理像素微调仍有差距。 |
| P01–P06 贴图 | 已实现文字、富文本、位图、图片文件、GIF、色卡、远程图片的显式开关、置顶、缩放、透明度、穿透、裁剪、分组和离屏恢复。数据库重启测试验证贴图状态恢复。系统虚拟桌面专属行为及部分批量操作仍有差距。 |
| U01–U04 设置和 CLI | 已实现默认热键和冲突提示、可配置热键、编辑器快捷键、自启、热角、文件模板、历史策略和多输出 CLI。自动化配置与参考产品的 INI 格式和全部扩展命令存在差异。 |
| 体验改进 | 历史可设置为 0 并清理，默认使用本地 OCR。滚动截图支持手动采集和重叠匹配，已用已知滚动距离的合成画面验证像素一致性。 |

## 可复现检查

| 检查 | 运行方式 |
| --- | --- |
| 编辑器、操作流程、存储、坐标和拼接 | 设置 `QT_QPA_PLATFORM=offscreen` 后执行 `python -m pytest -q` |
| 界面和离线识别 | `python run_snaploom.py --smoke-test-ocr` |
| 原生 Windows 或 X11 像素 | 在有图形桌面的会话中设置 `SNAPLOOM_TEST_DESKTOP=1`，使用 Windows 或 X11 后端执行 `python -m pytest -q tests/test_capture.py tests/test_native_interactions.py` |
| 各架构离线安装包 | 在目标系统执行 `python packaging/build.py --smoke`。GitHub Actions 在原生架构运行。 |

## 1.0.1 用户操作回归

| 操作 | 验证结果 |
| --- | --- |
| 悬停、贴图、关闭、恢复 | 悬停按钮不访问剪贴板。显式点击可贴出网址文字并用 × 隐藏。菜单随贴图隐藏，超出屏幕的贴图仍能点击 ×，鼠标穿透的贴图可从列表隐藏。覆盖拖放文件、手动恢复后再次贴图和重启恢复。 |
| 截图与框选 | 覆盖主窗口、托盘、键盘操作、重复选区、活动窗口、自定义尺寸和白板。逐像素检查反向拖选、缩小、移动、调整大小、亮暗画面和 Alt 放大镜。桌面测试读取实际显示的像素，检查旧边框是否清除。 |
| 标注、输出和取消 | 覆盖标注撤销与重做、复制、快速保存、复制为文件、取消保存后重试、多输出命令、关闭子菜单、截图取消及取图失败后重试。 |
| 历史、设置、识别与拼接 | 覆盖历史预览、确认清理、快捷键设置与重启、二维码识别与复制、滚动帧不重叠后重试。打包冒烟测试验证离线 OCR。 |

## 1.0.2 用户入口和标注回归

| 操作 | 检查内容 |
| --- | --- |
| 工具栏输入 | 实际点击线宽箭头和输入框，使用 Tab、方向键、Enter、Esc，检查输入焦点、数值和输出像素。覆盖普通截图、窄屏、编号和贴图编辑。 |
| 样式与设置 | 调整线宽、颜色、填充、线型、模糊和马赛克强度。验证截图、贴图编辑、历史预览和重启后沿用设置，以及关闭记忆、取消清除和保存清除。 |
| 单步撤销 | 验证连续绘制、修改已有标注线宽、撤销多段线的一个点、重做，以及撤回一次清空。 |
| 其他用户入口 | 从主窗口点击当前屏幕和所有屏幕，从历史复制、保存和贴图，从列表跨组独显和取消选择。点击快速保存、复制为文件和打印，验证失败或取消后可继续编辑。 |

## 1.0.3 取图和光标回归

| 操作 | 检查内容 |
| --- | --- |
| 主窗口点击「区域截图」 | 在 Windows 桌面把主窗口放在已知背景上，连续三次截图，逐像素比较原背景和编辑器冻结的取图。1.0.2 会把淡出窗口像素留在取图中。 |
| 刷新截图 | 框选后按 F5，确认重新取图的背景与原始像素一致，按 Esc 返回主窗口。 |
| 工具栏光标 | 在原生桌面窗口中依次向画布、工具栏、画笔按钮和线宽输入框发送鼠标移动，再返回画布，验证鼠标指向的控件与光标形状。离屏测试另覆盖浮动工具栏、下拉菜单和内嵌编辑器。 |

## 1.0.4 悬浮贴图入口回归

| 操作 | 检查内容 |
| --- | --- |
| 悬浮剪贴板内容 | 悬停不读取剪贴板，显式点击才创建贴图。用 F3 再次贴出相同内容时创建新贴图，已有隐藏贴图保持收起。空剪贴板给出复制提示。 |
| 恢复最近隐藏的贴图 | 通过主窗口和托盘操作，使用已经保存的贴图。检查剪贴板更新、显示或删除其他隐藏贴图、重启及多张贴图的隐藏顺序。 |

升级后，旧版隐藏记录在首次恢复时按创建顺序从新到旧排列。之后隐藏的贴图按实际隐藏时间恢复。

## 1.0.6 功能与交互走查

| 用户入口 | 预期与回归场景 |
| --- | --- |
| 主窗口、托盘和截图热键 | 单击或双击托盘打开工作台，从托盘菜单或截图热键开始取图。覆盖区域、当前屏幕、所有屏幕、当前窗口、上次区域、尺寸与延时、白板。尺寸对话框内再次触发截图时保留原流程。白板只显示适用的尺寸和背景选项。 |
| 框选、缩放与画布按键 | 鼠标和键盘均可框选，进行中的框选先由 Esc 取消。调整选区或缩小边界时保持冻结画面和原像素对应。覆盖窗口建议、F5 刷新、放大镜、方向键、历史选区顺序、选区比例与屏幕边缘。 |
| 标注与设置 | 覆盖工具切换、线宽、编号、文字、样式、马赛克、实色遮盖、重做和单步撤销。调整选区后，原有标注和遮盖仍对准原画面。编辑数字时 Enter 确认数值，Esc 放弃当次输入。 |
| 复制、保存、打印与命令输出 | 复制图像、复制为文件、快速保存、选路径保存、悬浮贴图分别执行各自操作。测试取消或失败后保留画布、自动保存失败后继续使用已复制的图像，以及命令行待确认输出的独立入口。打印流程使用对话框替身。 |
| 滚动截图 | 添加下一帧前隐藏面板，按设置隐藏的贴图在采集期间保持收起。测试无重叠重试、取消保存及写入失败，已拼好的画面可继续输出。 |
| OCR、条码和取色 | 识别保留画布，可取消等待，迟到的结果不会弹窗。覆盖识别繁忙、无结果、复制结果、保留原文字和二维码。离线 OCR 模型随包验证，云 OCR 的实网调用未纳入本轮验收。 |
| 贴图和分组 | 区分单张隐藏、整组暂时隐藏和切换分组。列表显示缩略图或文字与状态，Enter 显示，Delete 需确认。覆盖鼠标穿透恢复、移出屏幕后找回、右键菜单和拖选缩略图、裁剪、标注、分组切换及重启恢复。 |
| 历史与隐私 | 保存选中记录，刷新列表时继续操作同一条记录。Enter 打开预览，预览中的「新建悬浮贴图」明确说明结果。覆盖历史复制、保存、贴图、删除和取消清空。减少历史上限时确认实际将删除的条数。 |
| 全局与编辑器快捷键 | 分开显示每项当前绑定，可留空或恢复默认。测试无效键、重复键、全局与编辑器冲突、Windows 系统占用时保留旧绑定、保存和取消。 |

Windows 和 Linux X11 的原生桌面测试及各架构的打包冒烟检查见 [v1.0.6 构建](https://github.com/peterwangze/snaploom/actions/workflows/release.yml?query=branch%3Av1.0.6)。macOS 屏幕录制授权和 Linux Wayland 合成器行为仍待相应登录会话实测。

## 1.0.8 用户交互覆盖

| 操作范围 | 自动回归与结果检查 |
| --- | --- |
| 主窗口和托盘 | 逐项核对主页按钮和托盘菜单入口。向窗口派发鼠标事件或用方向键、Enter 选菜单项，验证命令路由、打开文件取消和成功、托盘中键贴图、历史入口和退出。见 [工作台流程](../tests/test_user_journeys.py)。 |
| 截图入口和输出 | 区域、当前窗口、当前屏幕、所有屏幕、重复选区、尺寸与延时、白板、热角和取色。覆盖截图快捷键、保存、复制、打印、OCR、条码、滚动拼接、命令输出，以及取消、失败和重试后的选区、文件或剪贴板。见 [入口与输出](../tests/test_entry_points.py)。 |
| 编辑器和标注 | 逐项点击标注工具并触发相应快捷键，检查选区、笔迹和导出像素。覆盖 Tab、Enter、Esc、线宽、颜色、填充、样式、编号、文字、撤销、重做、尺寸和比例。普通工具栏、浮动工具栏和内嵌编辑器都经过焦点切换检查。见 [编辑器控件](../tests/test_editor_controls.py)。 |
| 贴图和分组 | 测试剪贴板、文件和颜色输入，覆盖菜单项、鼠标拖动、滚轮和按键、缩略、尺寸、显隐、分组、穿透恢复与删除确认。检查操作后的尺寸、像素、窗口状态和本机记录。见 [贴图操作](../tests/test_pin_interactions.py)。 |
| 历史和设置 | 实际操作预览、Enter、小键盘 Enter、Delete 和清空确认。逐个修改设置字段并验证保存、取消、恢复默认、冲突和重启持久化。见 [工作台流程](../tests/test_user_journeys.py) 和 [标注设置](../tests/test_annotation_preferences.py)。 |
| 原生与显示环境 | Windows 真实窗口复测鼠标、线宽、拖选及桌面像素。Windows 快捷键用真实系统注册和线程消息检查六个动作及释放。持续集成在 Windows 11 和 Fusion 样式下分别跑 100%、125%、150%、200% 四档缩放，发布时另跑 Windows 和 Linux X11 原生检查。见 [原生交互](../tests/test_native_interactions.py) 和 [回归工作流](../.github/workflows/interactions.yml)。 |

应用控件、菜单导航和结果使用实际 Qt 事件验证。文字外观和编号二级菜单通过菜单动作验证状态变化，系统字体和颜色对话框使用受控结果。文件选择、打印服务、外部程序、网络和部分系统钩子也使用受控边界，避免访问真实用户数据和服务。macOS 权限、Wayland 合成器、混合 DPI 多屏和实体设备仍需在对应环境实测。

Windows 可从仓库根目录执行 `./.github/scripts/test-editor-matrix.ps1` 复跑样式和缩放矩阵。使用项目虚拟环境时，可通过 `-Python ./.venv/Scripts/python.exe` 指定解释器。

## 发布包的环境边界

- Windows x64 离线安装通过 Inno Setup，提供安装和免安装两种形式。当前包无 Authenticode 签名。
- macOS Intel 和 Apple Silicon 分别打包，构建机验证挂载、应用启动及离线识别。用户桌面上屏幕录制、辅助功能授权、快捷键和 Retina 多屏仍需实机验收。应用包采用临时签名，尚无 Apple 公证。
- Linux x64 和 ARM64 分别打包，验证了 Xvfb 中的 X11 捕获、安装、启动、离线识别和卸载。Wayland 需具有相应的 XDG 截图和快捷键门户，实际授权和贴图行为仍需在 GNOME、KDE 等合成器的登录会话中验证。
